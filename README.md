# project-notes

This branch holds Claude's notes for the AnyPS5 fork: project state, routine prompts and helper scripts. It contains no code and is never merged.

- `STATE.md`: where everything stands, the rules, the environment and the decisions. Read it first.
- `ROUTINES.md`: the full prompts of the two nightly routines.
- `upstream-prs/`: PR descriptions for the branches prepared for upstream.
- `remerge_debt.py`: merges docs/dev/TechnicalDebt.md entry by entry.
- `COLD_BOOT.md`: the prompt for starting a fresh chat on this project.
